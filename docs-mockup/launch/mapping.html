Guides / Mapping model

The mapping model

Three fixed rules turn a record into sound. They are documented, deterministic, and free of learned parameters: the same record and the same rules always return the same audio. This page specifies each rule, then gives the API reference for the v0.3.1 surface.

A sonification is only honest if you can say exactly how the numbers became the sound, and get the same sound back tomorrow. Xuanji fixes three channels. Nothing else touches the audio, and nothing is learned or tuned per record.

1. Brightness to pitch

Brightness sets the frequency of the tone. The mapping is logarithmic in flux (linear in magnitude), which matches both how the eye judges brightness and how the ear judges pitch, so equal steps in magnitude are equal musical intervals. Magnitudes are inverted for you: a smaller magnitude is brighter, and brighter reads higher.

BrightnessToPitch(f_lo=220, f_hi=1760, scale="mag", clip=True)
  • f_lo, f_hi float, Hz · the pitch range. The dimmest sample maps to f_lo, the brightest to f_hi. Two octaves is a good default.
  • scale "mag" | "flux" · whether the input array is magnitudes (inverted) or normalized flux (not inverted).
  • clip bool · clamp out-of-range samples to the endpoints rather than letting the tone run off the scale.

2. Time to tempo

Record-time is compressed to playback-time by one linear factor. You set either the total clip length or, for periodic data, how many cycles to play. The gaps between observations are preserved exactly: a two-week hole in the record is a two-week hole in the sound, scaled by the same factor as everything else. The library never interpolates across a gap.

TimeToTempo(seconds=None, cycles=None, gap="preserve")
  • seconds float · total playback length; the whole record span is fit to this.
  • cycles int · for data with a declared period, play this many periods instead of setting a fixed length.
  • gap "preserve" | "mark" · preserve keeps silent gaps to scale; mark adds a faint tick at each gap edge so a listener can hear where the record went dark.

3. Position to stereo

Where the object stood in the sky sets the stereo image. In azimuth mode the object pans left to right by its horizontal angle; in hemisphere mode the pan carries declination. For a moving object (a comet track) the pan follows the recorded motion, so you hear it cross the sky. Positions are placed through Astropy in the coordinate frame of the record's own date, with precession applied.

PositionToStereo(coords, mode="azimuth", width=0.9)
  • coords SkyCoord | SkyPath · a fixed position or a dated track. Precession to the record's epoch is handled by Astropy.
  • mode "azimuth" | "hemisphere" | "fixed" · what the pan encodes.
  • width float, 0-1 · how far toward the channel extremes the pan is allowed to travel.
Uncertainty is a first-class input Every rule accepts an uncertainty channel. render(…, jitter="date_sigma") softens each note's onset by its dated uncertainty; jitter="pos_sigma" widens the stereo image by the position error. The sound is never allowed to claim more precision than the record holds. A record whose cross-identification is only a candidate carries that flag through to the audio, so a debated event is never played as if it were settled.

API reference

The public surface is deliberately small. In v0.3.1 it is nine objects and four module functions, and it covers everything on this site. The surface is frozen for the 0.3 line; anything that would change it waits for a minor release and a changelog entry.

Records

xj.from_record(record_id) → Record

Load a curated, cross-identified record by its XJ- id. The returned Record exposes .source, .cross_id, .confidence, .coords, and constructors .light_curve() and .sky_path().

xj.records(kind=None) → list[Record]

Every curated record (ten in v0.3.1), optionally filtered by kind ("supernova", "nova", "comet", "eclipse", "sunspot", "meteor", "chart"). Iterating this is how the gallery is regenerated.

Sonifier

xj.Sonifier(pitch, tempo=None, stereo=None, timbre="sine")
  • pitch BrightnessToPitch · required. The brightness-to-pitch rule.
  • tempo TimeToTempo · how record-time maps to playback-time.
  • stereo PositionToStereo · optional; omit for a centred mono image.
  • timbre "sine" | "triangle" | "pluck" · the tone colour. Timbre carries no data; it is a listening aid only.
Sonifier.render(series, jitter=None) → Audio

Apply the configured rules to a LightCurve or SkyPath and return the Audio. jitter selects an uncertainty channel to fold in.

Determinism guarantee Given the same input arrays, the same rule parameters, and the same library version, render returns byte-identical audio. This is tested in CI against stored checksums for every curated record, so a regression in the mapping cannot ship silently.
