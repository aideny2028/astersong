Project / How to cite

How to cite Xuanji

If Xuanji helped your teaching, your outreach, or your research, please cite it. Cite the peer-reviewed paper for the method, and the versioned software DOI for the exact code you ran. Both are below, formatted and ready to paste.

Cite the paper

The library and its method are described in a short, peer-reviewed paper in the Journal of Open Source Software. This is the citation to use when you refer to Xuanji in a methods section, a syllabus, or a talk.

referenceAPA
Yeoh, A., Okonkwo, M., Ramanathan, D., Halvorsen, S., Meng, L., &
Balasubramanian, P. (2026). Xuanji: sonification of historical
astronomical records. Journal of Open Source Software, 11(118), 6842.
https://doi.org/10.21105/joss.06842
paper.bibBibTeX
@article{Yeoh2026Xuanji,
  title   = {Xuanji: sonification of historical astronomical records},
  author  = {Yeoh, Aiden and Okonkwo, Maya and Ramanathan, Dev
             and Halvorsen, Sofia and Meng, Lucas
             and Balasubramanian, Priya},
  journal = {Journal of Open Source Software},
  year    = {2026},
  volume  = {11},
  number  = {118},
  pages   = {6842},
  doi     = {10.21105/joss.06842},
  url     = {https://doi.org/10.21105/joss.06842}
}
Authorship Xuanji is authored by Aiden Yeoh and its volunteer contributors. The paper's author list matches the maintainer credits on the overview. No advisor or endorser is named; the review seat is open.

Cite the software version

For reproducibility, cite the exact release you ran, not just the paper. Every tagged release is archived on Zenodo and gets its own DOI; a concept DOI resolves to the latest version. The DOIs below are reserved and activate on first public deposit.

@software{Yeoh2026XuanjiSoftware,
  title     = {Xuanji: a sonification engine for historical
               astronomical records},
  author    = {Yeoh, Aiden and {The Xuanji contributors}},
  year      = {2026},
  version   = {1.4.2},
  publisher = {Zenodo},
  doi       = {10.5281/zenodo.7724011},
  url       = {https://github.com/xuanji-project/xuanji},
  note      = {DOI reserved; activates on public deposit}
}

Xuanji also ships a CITATION.cff file, so GitHub and Zenodo can build the citation for you, and reference managers can import it directly.

pythonget the citation in code
import xuanji as xj
print(xj.citation())        # formatted reference
print(xj.citation("bibtex"))  # the BibTeX above

Citing an individual record

Xuanji plays records; it does not author them. When you cite a sonification, cite the library for the method and the record's own primary source for the observation. Each curated record carries its citation with it.

pythona record's own source
rec = xj.from_record("XJ-1054")
print(rec.source)      # 'Song Shi, Astronomical Treatise'
print(rec.cross_id)    # 'Crab Nebula (M1), Taurus'
print(rec.confidence)  # 'secure'
print(rec.cite())      # source + archive DOI, formatted

The records themselves live in the sibling Xuanji Archive, which carries its own Zenodo deposit and per-record citations. If your work leans on a specific record's cross-identification, cite the archive as well as this library.

One line, honestly "Rendered with Xuanji v1.4.2 (Yeoh et al., 2026) from the record's primary source; the identification is graded secure." That single sentence names the tool, the version, the paper, and the confidence, which is everything a reader needs to check you.
