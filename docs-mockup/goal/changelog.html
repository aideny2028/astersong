Project / Changelog

Changelog

Every notable change, newest first. Xuanji follows semantic versioning: the mapping model is stable across the 1.x line, and any change that would alter the audio a record returns is a breaking change and would bump the major version. Each tagged release is archived on Zenodo with its own DOI (see how to cite).

Reading this file Changes are grouped as Added, Changed, Fixed, and Deprecated. Anything that touches the sound of an existing record is called out explicitly, because determinism is the promise this project keeps.

1.4.2 · 2026-06-18

patch · DOI 10.5281/zenodo.7724011 (reserved)

  • Fixed a rounding drift in TimeToTempo that could shift the final sample by one frame on very long records; checksums for all 42 curated records were re-verified and are unchanged at audio resolution.
  • Fixed a matplotlib 3.9 deprecation warning in xj.plot().
  • Changed the wheel to ship the bundled record archive as a single compressed asset, cutting install size by about a third.

1.4.0 · 2026-05-02

minor · DOI 10.5281/zenodo.7719884

  • Added six curated records, bringing the gallery to 42: the guest star of 393, SN 1181 (Cassiopeia, remnant still debated), the Great Comet of 1577, the 1361 Ming eclipse, the 1128 sunspot, and the 1770 great aurora.
  • Added xj.records(kind=...) filtering and the one-line gallery build loop documented on the install page.
  • Added grid="continuous" to bypass 12-tone equal temperament for listeners who want the raw pitch surface.
  • Changed nothing in the audio of existing records; all prior checksums hold.

1.3.0 · 2026-03-14

minor · DOI 10.5281/zenodo.7711204

  • Added the SkyPath data object and PositionToStereo support for moving objects, so a comet's recorded night-by-night track pans across the stereo field. First used by the Halley 1066 record.
  • Added the hemisphere stereo mode alongside azimuth and fixed.
  • Fixed a precession bug where a record's position was placed in the J2000 frame instead of the frame of its own date; positions now go through Astropy at the record's epoch. This changes the stereo image of five records; their checksums were updated and the change is noted in each record's history.

1.2.0 · 2026-01-20

minor · DOI 10.5281/zenodo.7702553

  • Added uncertainty as a first-class input: date_sigma and pos_sigma on the data objects, and render(..., jitter=...) to fold a record's dating or position error into the onset and the stereo width. A coarse record now sounds coarse.
  • Added gap="mark" to place a faint tick at each observation gap, so a listener hears where a record went dark.
  • Changed the default for text-derived records to render with jitter="date_sigma", matching how the paper reports them.

1.1.0 · 2025-11-08

minor · DOI 10.5281/zenodo.7688120

  • Added a conda-forge feedstock: conda install -c conda-forge xuanji.
  • Added the timbre option on Sonifier (sine, triangle, pluck), documented as a listening aid that carries no data.
  • Added xj.data.load_kepler and xj.data.load_aavso helpers for bringing your own modern light curves.
  • Fixed a Windows path bug in Audio.write for FLAC output.

1.0.0 · 2025-09-30

major, first stable · DOI 10.5281/zenodo.7671009

  • Added the peer-reviewed Journal of Open Source Software paper (accepted September 2025) describing the mapping model and the reconstruction-and-uncertainty method.
  • Added the determinism guarantee: given the same input, parameters, and version, render returns byte-identical audio, checked in CI against stored checksums for every curated record.
  • Changed the public API to its stable surface: BrightnessToPitch, TimeToTempo, PositionToStereo, Sonifier, LightCurve, Record, Audio, and the module shortcuts. No breaking changes are allowed within 1.x.
  • Added the curated gallery at 24 records, each with a primary source, a modern cross-identification, and a confidence grade.

0.9.0 · 2025-07-15

release candidate

  • Changed the record schema to require a confidence field, so no record can ship without stating how firm its identification is.
  • Added the schema validator and a CI job that rejects a record missing a source or a cross-id.
  • Deprecated the pre-1.0 quick_sonify() convenience function in favour of xj.sonify().

0.5.0 · 2025-04-11

  • Added xj.plot(), the two-panel plate (waveform above, log-frequency spectrogram below), which became the house figure convention.
  • Added the first small gallery: SN 1006 (Lupus), SN 1054 (the Crab, in Taurus), SN 1604 (Kepler), and the Dunhuang star chart (~700 CE).
  • Changed pitch mapping to snap to 12-tone equal temperament by default.

0.3.0 · 2025-02-02

  • Added TimeToTempo and PositionToStereo, completing the three-channel model.
  • Added the LightCurve object and the bridge to the sibling record archive via xj.from_record().

0.1.0 · 2024-12-09

first public release

  • Added the first working sonifier: BrightnessToPitch and a mono renderer, built to give one archive's records a second sense. The whole thing fit in one file and played the guest star of 1054 as a falling tone.
Before 0.1 Xuanji started as one student's script to hear an archive of historical sky-records rather than only read them. The three-rule model, the honesty about uncertainty, and the refusal to invent data between points were there from the first commit; everything since has been making them reproducible, tested, and citable.

An open-source engine that renders historical astronomical records as sound. Created by Aiden Yeoh and maintained by the Xuanji contributors. Built on Astropy and the scientific-Python stack.
