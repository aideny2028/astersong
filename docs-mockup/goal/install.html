Getting started / Install

Install and first sound

Xuanji is a pure-Python package with a small, pinned scientific stack. Installing it and rendering a curated record takes about a minute.

Requirements

Xuanji targets Python 3.10 and newer, on Linux, macOS, and Windows. The core runtime is deliberately short.

PackageVersionUsed for
python≥ 3.10the interpreter
numpy≥ 1.24light-curve and audio arrays
scipy≥ 1.10resampling and filtering
astropy≥ 5.3coordinates, precession, time scales
soundfile≥ 0.12writing WAV and FLAC ([audio] extra)
matplotlib≥ 3.7the two-panel plate ([audio] extra)

Install

Pick one. The [audio] extra pulls in soundfile and matplotlib so you can write files and draw plates; without it you still get the raw audio array.

pip install "xuanji[audio]"
conda install -c conda-forge xuanji
git clone https://github.com/xuanji-project/xuanji
cd xuanji
pip install -e ".[audio,dev]"
pytest -q            # 214 passed
a virtual environment (venv or conda) is recommended, not required
Note On Linux, soundfile needs the system libsndfile library. On Debian or Ubuntu: sudo apt-get install libsndfile1. conda-forge ships it automatically.

The record archive is bundled with the package, so no network access is needed after install. To track new records between releases, install the optional data channel with pip install "xuanji[archive]", which pulls curated additions from the sibling archive's tagged releases.

Verify the install

Confirm the version and that the bundled records load.

pythonverify
import xuanji as xj
print(xj.__version__)          # 1.4.2
print(len(xj.records()))       # 42 curated events
output
1.4.2
42

Quickstart: sixty seconds to a sonification

The fastest path uses a curated record from the archive. Each record already declares its source, its cross-identification, and the mapping it was published with, so sonify needs nothing else.

quickstart.pypython
import xuanji as xj

# 1. load a curated, cross-identified record
rec = xj.from_record("XJ-1054")      # SN 1054, the Crab, Taurus
print(rec.source)                    # 'Song Shi, Astronomical Treatise'
print(rec.cross_id, rec.confidence)  # 'Crab Nebula (M1)' 'secure'

# 2. render it to sound with the record's declared mapping
audio = xj.sonify(rec)                # -> Audio(samplerate=44100, stereo)

# 3. write the file and the two-panel plate
audio.write("sn1054.wav")
xj.plot(rec, audio).savefig("sn1054.png", dpi=150)

That is the whole loop: load a record, render it, write it. To sonify your own data instead of a curated record, build a LightCurve or a SkyPath and pass it to a Sonifier you configure. The tutorial walks through three worked examples, and the mapping model documents every rule and parameter.

Render the whole gallery at once

New in the 1.x line: iterate the archive and render every record with its declared mapping. This is the command that regenerates the gallery.

build_gallery.pypython
import xuanji as xj

for rec in xj.records():
    audio = xj.sonify(rec)
    audio.write(f"out/{rec.id}.flac")
    xj.plot(rec, audio).savefig(f"out/{rec.id}.png", dpi=150)
    print(rec.id, rec.cross_id, rec.confidence)
What it does not do Xuanji never invents data between your samples and never adds notes that are not in the record. If a night is missing from the source, it is missing from the sound. That is the point.
