# DESIGN.md, Xuanji sonification library, docs site (launch + goal, one system)

This artifact is the documentation site for **Xuanji**, the open-source Python
library that renders astronomical events and light curves as sound. It is the
"engine" half of the Xuanji project (the other half is the sky-records archive,
built as a separate artifact); both share the one Xuanji brand and logo, and
read as two faces of one project, not two projects.

The site ships in two versions on ONE design system (rule 12be): `launch/` (the
honest first public release, a pre-1.0 library maintained by one student) and
`goal/` (the same library at 1.x, with a contributor team, a JOSS paper, and
broad adoption). Same masthead, type, palette, grid, logo, and footer; only the
content and scale change, plus a version pill in the masthead.

## Archetype (and the taste anti-patterns bound against it, rule 12bo)

Archetype: **academic / scientific-Python library documentation**, not a SaaS
landing page, not a startup, not a "project microsite with a hero and three
feature cards." Bound NOT-to-do list for this archetype:

- No marketing gradient, no glassmorphism, no neon glow, no hero video.
- No three-feature-card triad; no giant centered tagline hero with a single
  button; no emoji icons.
- Function over flash: the install command, the code sample, the API signature,
  and the figure are the design. Show the tool, do not sell it.
- A real docs skeleton: masthead + left docs sidebar + content column + an
  "on this page" mini-TOC, monospace-forward, dense but legible.

This makes the tool site deliberately DIFFERENT from its sibling, the Xuanji
archive (a warm-parchment, plate-first, serif-bodied scholarly catalog). Same
brand, different archetype, different skeleton, so the folder never converges on
one recolored template (rule 12ba).

## Named references (best-in-class, and what each gives us)

1. **librosa documentation** (librosa.org) - the audio-library archetype. Taken:
   the example **gallery of waveform + log-frequency spectrogram figures** (the
   two-panel figure is librosa's house convention), the mono-labelled figure
   captions, and the compact API "quick reference" table.
2. **Astropy** (astropy.org and docs.astropy.org) - scientific-Python authority.
   Taken: the **install-forward masthead** with a version pill, the sober "core
   package / affiliated ecosystem" framing, the left docs sidebar, and the
   "cite us / DOI" discipline in the footer.
3. **Astronify** (STScI, astronify.readthedocs.io) - the closest real sibling, a
   package that turns astronomical time-series into sound. Taken: the
   **mapping-parameter vocabulary** (pitch mapping, the series/sonifier object,
   the accessibility-first rationale) that our Mapping model page extends.
4. **NumPy.org (2020+ redesign)** - landing-page craft for a scientific package.
   Taken: the hero that puts a **live code sample beside the pitch**, the
   install-tab widget (pip / conda / source), and the ecosystem card row.

Open Design binding: direction **`tech-utility`** (GitHub / Datadog / Sentry
posture: data-dense, monospace-friendly, hairline tables, no hero images as
decoration) for the docs chrome, warmed to the Xuanji brand; the landing hero
borrows the density restraint of `design-systems/stripe` docs. The sibling
archive is bound to an editorial/scholarly direction, so the two stay distinct
on all three axes (palette+posture, type pairing, layout skeleton).

## The one memorable detail

**The score strip.** A real spectrogram band (generated by the library from a
"score of the sky": several descending guest-star fades with grain transients)
runs as a hairline divider under the masthead and between major sections. It
reads as a musical staff made of data, and it is the single motif that ties the
whole site to what the tool does. Reprised small in the footer.

Second signature: the **mapping console**, a labelled three-channel diagram
(brightness to pitch, time to tempo, sky-position to stereo) that appears on the
landing and anchors the Mapping model page.

## Type

- **Display + UI + body:** IBM Plex Sans (OFL) - a humanist grotesque that reads
  as "scientific software," distinct from the sibling archive's Fraunces +
  Newsreader serif world. Headings at 600/700 with tight negative tracking.
- **Code / labels / metadata:** IBM Plex Mono (OFL). Tabular numerics.
- **Wordmark + one thesis pull-quote:** Cormorant (OFL), the Xuanji brand face,
  so the brand voice still speaks once per page without turning the docs serif.
- **Chinese:** Noto Serif SC (OFL) for Han glyphs (璇玑, source titles).
- Avoided by design: Inter, Roboto, Arial, Montserrat, Poppins, Space Grotesk,
  and every system default.

## Color (role tokens, WCAG-verified by measurement, rule 12bp)

Ink on clean paper with the Xuanji cinnabar accent, plus dark "instrument
panels" for the hero, the figures, and the footer (spectrograms live on dark; it
is the authentic audio-tool look and it separates this site from the archive's
all-light parchment).

| Role | Hex | On | Ratio | Use |
|---|---|---|---|---|
| ink | `#1C1815` | paper | 17.0 | body, headings |
| ink-soft | `#5A5346` | paper | 7.35 | muted text, captions |
| accent (cinnabar) | `#B3382B` | paper | 5.77 | links, kickers, rules |
| accent-strong | `#9E2E22` | paper | 7.07 | link hover, emphasis |
| paper | `#FCFBF7` | - | - | docs ground (cooler/lighter than the archive's parchment) |
| surface | `#F3EFE6` | - | - | inline code, callouts, panels |
| on-dark (parchment) | `#F1E7CD` | dark `#16130E` | 15.0 | text on instrument panels |
| accent-on-dark | `#E68A5C` | dark | 7.19 | links + small text on dark |
| accent-rule-dark | `#CE5340` | dark | 4.64 | large accents + rules on dark |

**Recorded substitution (rule 12bp):** the brightened cinnabar `#CE5340` fails
small-text AA on the dark panel (4.35:1), so small text and links on dark use
`#E68A5C` (7.19:1); `#CE5340` is reserved for large accents and rules on dark.
The accent appears on a minority of elements (a rule, a kicker, one link state),
so it stays decisive, not decorative.

## Layout skeleton (distinct from the archive)

- **Masthead (sticky):** Xuanji wordmark + mono tag "sonification library" +
  version pill + top nav (Docs, Tutorial, Mapping, Gallery, GitHub) + a
  copyable `pip install xuanji` chip. Underlined by the score strip.
- **Landing:** a dark hero (name in Cormorant, tagline, install tabs, a code
  sample card, the mapping console), then a light docs body: what it does (three
  asymmetric prose points, not cards), a featured sonification (SN 1054, big
  figure + player + story), the ecosystem row, a mapping teaser, footer.
- **Inner pages:** left docs sidebar (Overview, Install, Quickstart, Tutorial,
  Mapping model, API reference, Gallery, Cite, Changelog) + content column +
  right "on this page" TOC on wide screens.
- **Footer:** horizontal multi-column (Project / Docs / Community / Cite) on the
  dark ground, with the mono seal, a one-line blurb, and the image-credit line.

## Imagery

British Library), the Soochow/Suzhou planisphere rubbing (engraved 1247 CE), the

All credited in `IMAGE-CREDITS.md` and in the footer where a license (CC BY /

reference sonification engine from reconstructed light curves (see
`provenance.md`); they are real data figures, not placeholder blocks.

## Astronomy accuracy locks (do not swap)

SN 1006 is in **Lupus** (brightest recorded stellar event); SN 1054 is in
**Taurus** and became the **Crab Nebula**; the Dunhuang star chart is **~700 CE**
(British Library); the Suzhou/Soochow planisphere was **engraved 1247 CE**
(drafted ~1193). The gallery copy and figure labels follow these exactly.
